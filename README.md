# مخيم الحاشي — نظام السحب على الجوائز (Lucky Draw)

نظام سحب على الجوائز ثنائي اللغة (عربي/إنجليزي) لـ **مخيم الحاشي**، منفَّذ من تصميم Claude Design.
خفيف، سريع، ويتحمّل ضغط التسجيل العالي أثناء الحملات.

## شقّا الاشتراك (سحوبات متوازية)

الاشتراك ينقسم لشقّين، لكل شق **سحب وجائزة (سيارة) وقائمة مشاركين مستقلة**، ويعملان بالتوازي:

| الشق | التسجيل | مثال الجائزة |
|------|---------|--------------|
| **الزوّار** (`visitor`) | الاسم + رقم الهاتف | سيارة الزوّار |
| **المصوّرون** (`photographer`) | الاسم + الهاتف + **3 روابط ريلز إنستقرام** | سيارة المصوّرين |

- تقدر تنشئ **أكثر من سحب** من «إعداد السحب»، وكل سحب تختار له شقّه.
- **سحب واحد نشط لكل شق** في نفس الوقت (تفعيل سحب الزوّار لا يؤثر على سحب المصوّرين).
- صفحة الاشتراك العامة فيها مبدّل بين الشقّين؛ شق المصوّرين يُظهر حقول الريلز الثلاثة.
- في لوحة التحكم: **مبدّل السحوبات** في الشريط العلوي يحدّد أي سحب تديره (اللوحة/المشاركون/الفائزون)، وشاشة `/live` فيها مبدّل لاختيار أي سيارة تسحبها.

## الستاك

| الطبقة | التقنية | السبب |
|--------|---------|-------|
| **Frontend** | صفحات HTML/CSS static + Vanilla JS (ES modules) | تُخدَّم من CDN/nginx = تصفّح لحظي، تحمّل قراءة غير محدود |
| **Backend** | Node.js + [Fastify](https://fastify.dev) | من أسرع فريمويركات Node، overhead منخفض، يبلع دفعات التسجيل |
| **Data** | SQLite (WAL mode) عبر `better-sqlite3` | صفر إعداد، كتابة متسلسلة سريعة. الطبقة معزولة في `src/db.js` للترقية لـ Postgres |
| **Realtime** | WebSocket (`@fastify/websocket`) | مزامنة شاشة السحب المباشر + عدّاد المشتركين اللحظي |
| **WhatsApp** | [Wasender API](https://wasenderapi.com) | تأكيد تلقائي لكل مشترك + إشعار لكل فائز (وضع mock بدون مفتاح) |

## التشغيل

```bash
npm install
cp .env.example .env      # عدّل SESSION_SECRET والمفاتيح
npm start                 # أو: npm run dev  (إعادة تحميل تلقائي)
```

ثم افتح:

| الرابط | الوصف |
|--------|-------|
| `http://localhost:3000` | صفحة الاشتراك العامة (الجمهور / QR) |
| `http://localhost:3000/kiosk` | شاشة الكشك داخل المحل (تابلت) |
| `http://localhost:3000/admin` | لوحة تحكم المدير |
| `http://localhost:3000/live` | شاشة السحب المباشر (للعرض على الشاشة الكبيرة) |

**دخول تجريبي:** `info@alhashi.om` / `demo1234` (يُنشأ من `.env` عند أول تشغيل).

## بنية المشروع

```
src/
  server.js              تهيئة Fastify + تسجيل المسارات
  config.js              قراءة .env
  db.js                  SQLite + الـ schema (نقطة التبديل لـ Postgres)
  seed.js                المدير الافتراضي + حملة تجريبية
  auth.js                تجزئة كلمة المرور (scrypt) + جلسة كوكي موقّعة
  routes/
    public.js            /api/campaign, /api/register  (المسارات عالية الضغط)
    admin.js             تسجيل الدخول، الإحصائيات، المشاركون، الإعداد، الفائزون
    draw.js              التحكم بالسحب (اختيار الفائز)
    live.js              WebSocket
  services/
    draw.service.js      حساب المؤهلين + اختيار فائز عشوائي آمن (crypto) داخل معاملة
    whatsapp.js          موصّل Wasender
    hub.js               بث WebSocket
public/                  الواجهة (index/kiosk/admin/live + css + js + assets)
```

## الانتقال للإنتاج (High-scale)

الطبقات معزولة عمداً، فالترقية بسيطة:

1. **قاعدة البيانات:** بدّل `src/db.js` لـ PostgreSQL (مثل `pg`) — بقية الكود لا يتغيّر.
2. **Realtime أفقي:** استبدل `src/services/hub.js` بـ Redis pub/sub لتشغيل عدة نسخ خلف load balancer.
3. **الواجهة:** ارفع مجلد `public/` على CDN؛ اجعل Fastify يخدم الـ API فقط.
4. **Rate limiting:** أضِف `@fastify/rate-limit` على `/api/register` لصدّ الإساءة.
5. **WhatsApp:** أدخل مفتاح Wasender من **لوحة التحكم ← الإعدادات ← ربط واتساب** (يُحفظ في جدول `settings`)، أو ضع `WASENDER_API_KEY` في `.env` كبديل. المفتاح المحفوظ من الواجهة يَجُبّ قيمة `.env`، ولا يُعاد عرضه أبداً — فقط آخر 4 خانات.

## الرسائل النصية

نصوص رسائل واتساب تُحرَّر من **الإعدادات ← الرسائل النصية** (تُحفظ في جدول `settings`، والافتراضيات في `DEFAULT_TEMPLATES` داخل `src/services/whatsapp.js`):

- **رسالة تأكيد التسجيل** — تُرسَل لكل مشترك، مع مفتاح لإيقاف الإرسال التلقائي.
- **رسالة إشعار الفائز** — تُرسَل من زر «إشعار واتساب» في صفحة الفائزين.
- **المتغيّرات:** `{name}` · `{campaign}` · `{prize}` · `{store}` — اضغط على المتغيّر لإدراجه في موضع المؤشر، والمعاينة تتحدّث مباشرة ببيانات السحب النشط.

## الأمان
- كلمات المرور: scrypt + salt، مقارنة بزمن ثابت.
- الجلسة: كوكي `httpOnly` موقّع بـ `SESSION_SECRET`.
- اختيار الفائز: `crypto` غير متحيّز، داخل معاملة ذرّية (لا يتكرر فائز تحت التزامن).
- تحقّق من المدخلات + قيد فريد `(campaign, phone)` يمنع التسجيل المكرر.
